# ☕ Brew & Bean — Coffee Shop App

A stylish and modern coffee shop mobile application UI built with **Flutter** and **Dart**, featuring elegant typography, warm coffee-inspired colors, and a smooth shopping experience.

## 📱 About the Project

Brew & Bean is a beginner-friendly Flutter UI project designed to showcase a beautiful coffee shop ordering experience. Users can explore coffee options, view product details, save favorites, manage their shopping cart, and preview a checkout.

This project is ideal for beginners who want to practice Flutter UI design, widgets, navigation, and state management.

## ✨ Features

- 🏠 **Home Screen** — Welcome section, promotional banner, and featured coffees.
- ☕ **Coffee Menu** — Browse available coffees with search and hot/cold category filters.
- ❤️ **Favorites** — Add or remove coffees from your favorites list.
- 🛍️ **Shopping Cart** — Add products, adjust quantities, and calculate totals.
- 🔎 **Product Details** — View coffee images, descriptions, ratings, and prices.
- 💳 **Demo Checkout** — Preview the order total and place a demo order.
- 🎨 **Modern UI** — Cream backgrounds, coffee-brown accents, rounded cards, and elegant typography.
- 🔤 **Google Fonts** — Poppins for body text and Playfair Display for headings.
- 📱 **Bottom Navigation** — Easily switch between Home, Menu, Favorites, and Bag.

## 🛠️ Technologies Used

- **Flutter** — UI development framework.
- **Dart** — Programming language.
- **Google Fonts** — Custom typography.
- **Material 3** — Modern Flutter UI components.
- **Unsplash** — Online coffee photography.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK compatible with your Flutter installation
- FlutLab or another Flutter development environment
- Internet connection for downloading Google Fonts and coffee images

### Installation

**1. Clone or download the project**

If using Git:

```bash
git clone <your-repository-url>
cd helloworld
```

**2. Install dependencies**

Make sure your `pubspec.yaml` includes:

```yaml
dependencies:
  flutter:
    sdk: flutter
  google_fonts: 6.3.2
```

Then run:

```bash
flutter pub get
```

**3. Run the application**

```bash
flutter run
```

In FlutLab, save your files, fetch packages using Pub Commands, and click Run.

## 📋 Screens

1. **Home:** Welcome message, promotional banner, and featured coffee cards.
2. **Menu:** Searchable coffee catalog with hot and cold filters.
3. **Favorites:** A personalized list of saved coffees.
4. **Bag:** Quantity controls, subtotal, delivery charge, and total.
5. **Product Details:** Coffee information and add-to-cart action.
6. **Checkout Preview:** Demo order confirmation.

## 🧪 Current Limitations

- Checkout is for demonstration only; no real payment is processed.
- Product information and prices are sample data.
- Cart and favorites are stored in memory and reset when the app restarts.
- Coffee photos and Google Fonts require internet access and may not load offline.
- No backend, authentication, or live inventory is connected.
